# Wine Quality Analysis

## Overview

This project focuses on the analysis of wine quality based on its physicochemical properties. The dataset is sourced from the UCI Machine Learning Repository and contains information on various chemical attributes of red and white wine samples.

The objective is to analyse the relationship between these attributes and wine quality ratings through data exploration, statistical analysis, and machine learning techniques.

## Dataset

The Wine Quality dataset consists of two datasets:

- **Red Wine Dataset:** 1,599 observations
- **White Wine Dataset:** 4,898 observations
- **Total Observations:** 6,497

Each observation contains 11 physicochemical input variables and one output variable representing the wine quality score.

### Features

| Feature | Description |
|---|---|
| Fixed Acidity | Concentration of non-volatile acids |
| Volatile Acidity | Concentration of volatile acids |
| Citric Acid | Citric acid content |
| Residual Sugar | Amount of sugar remaining after fermentation |
| Chlorides | Chloride concentration |
| Free Sulfur Dioxide | Free sulfur dioxide concentration |
| Total Sulfur Dioxide | Total sulfur dioxide concentration |
| Density | Density of the wine |
| pH | Measure of acidity or alkalinity |
| Sulphates | Sulphate concentration |
| Alcohol | Alcohol content by volume |
| Quality | Sensory-based quality score (0–10) |

### Target Variable

The `quality` variable represents the sensory quality rating assigned to each wine sample.

## Objectives

- Perform exploratory data analysis on the Wine Quality dataset.
- Examine the distribution of physicochemical properties.
- Identify correlations between chemical attributes and wine quality.
- Determine the attributes that have a significant relationship with wine quality.
- Apply statistical and machine learning techniques to analyse and predict wine quality.
